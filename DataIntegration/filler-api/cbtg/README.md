## Общая документация по эндпоинтам для сервиса ЦБТГ
___

### Goszakup
endpoint - `/cbtg/goszakup/ad/{adNumber}`

Возможные ответы.
Пример запроса - `cbtg/goszakup/ad/10358494-1`.  

___

Если все в порядке, пример. HTTP статус код - 200
```json5
{
    "data": {
        "adNumber": "10358494-1",
        "adName": "Приобретение прочих товаров",
        "beneficiaryBin": "940340000312",
        "beneficiaryName": "РГУ \"Центрально-Казахстанский межрегиональный департамент геологии Комитета геологии Министерства индустрии и инфраструктурного развития Республики Казахстан \"Центрказнедра\"",
        "startDate": "2023-07-14 10:59:00",
        "endDate": "2023-07-21 10:59:27",
        "lots": [
            {
                "lotNumber": "61463437-КПКО2",
                "lotName": "Картридж",
                "amount": 35571.42,
                "adNumber": "10358494-1",
                "statusName": "Опубликован (прием заявок)",
                "statusCode": "PublishedBidAccept"
            },
        ],
        "statusName": "Опубликовано (прием заявок)",
        "statusCode": "PublishedOrderTaking"
    },
    "statusCode": "OK",
    "statusName": "OK"
}
```
Допустимые `statusCode` внутри `data`
```
* PublishedPriceOffers: Опубликовано (прием ценовых предложений)
* PublishedAdditionDemands: Опубликовано (дополнение заявок)
* PublishedOrderTaking: Опубликовано (прием заявок)
``` 
Недопустимые `statusCode` внутри `lots` для каждого лота. Они отсеиваются при фильтрации
```
* Cancelled: Отменено
```

___

Проверки идут в следующем порядке
* Поиск объявления, есть ли такое?
* Сколько закупок нашлось по данному номеру?
* Начался ли тендер
* Не завершился ли тендер
* Допустимый ли статус закупки (требуется ли по нему выпуск гарантии)
* Не пустой ли список лотов (мог стать пустым после фильтрации)
* Допустимый ли способ закупки

___

В случае если закупка не найдена
```json5
{
    "data": {},
    "statusCode": "adNotFound",
    "statusName": "Объявление с таким номером не найдено"
}
```

___

В случае если нашлось несколько объявлений/закупок но номеру ( совпадение недостаточно точное )
```json5
{
    "data": {},
    "statusCode": "foundMoreThanOneAd",
    "statusName": "Совпадение оказалось недостаточно точным, нашлось несколько подходящих по номеру объявлений"
}
```

___ 

В случае если тендер по закупке еще не начался

```json5
{
    "data": {},
    "statusCode": "tenderNotStarted",
    "statusName": "Тендер еще не начался"
}
```

В случае если тендер уже завершен
```json5
{
    "data": {},
    "statusCode": "tenderEnded",
    "statusName": "Тендер уже завершен"
}
```
___

В случае если статус закупки не допустим
```json5
{
    "data": {},
    "statusCode": "adBuyStatusNotAllowed",
    "statusName": "Статус закупки должен быть один из: Опубликовано (прием заявок), Опубликовано (дополнение заявок), Опубликовано (прием ценовых предложений)"
}
```

___

В случае неподходящего статуса закупки
```json5
{
    "data": {},
    "statusCode": "adTradeMethodNotAllowed",
    "statusName": "Неподходящий способ закупки"
}
```

___

В случае внутренней ошибки сервиса
```json5
{
    "data": {},
    "statusCode": "internalServerError",
    "statusName": "Internal Server Error"
}
```
HTTP код - 400


### Samruk

При условии что все в порядке
```json5
{
    "data": {
        "adNumber": "882029",
        "adName": "Пакет замком 25x35",
        "beneficiaryBin": "010940000162",
        "beneficiaryName": "Акционерное общество \"Эйр Астана\"",
        "startDate": "2023-07-13 14:15:00",
        "endDate": "2023-07-21 10:00:00",
        "lots": [
            {
                "lotNumber": "3288854",
                "lotName": "Пакет",
                "amount": 90000.0,
                "adNumber": "882029",
                "statusCode": "PublishedBidAccept"
            }
        ],
        "statusCode": "PublishedOrderTaking"
    },
    "statusCode": "OK",
    "statusName": "OK"
}
```

Порядок проверок
* Поиск объявления, есть ли такое? ( получение мета информации по объявлению )
* Сколько закупок нашлось по данному номеру? точное ли совпадение?
* Находится ли на основе мета информации общая информация об объявлении? Общая/по лотам?
* Начался ли тендер
* Не завершился ли тендер
* Допустимый ли статус закупки (требуется ли по нему выпуск гарантии, допустимый - PUBLISHED, преобразуется далее в PublishedOrderTaking)

Ответы аналогичны goszakup (относительно `statusCode` ключа).
Относительно `statusName` отличается ответ в случае если способ закупки не найден.

Будет 
```json5
{
    "data": {},
    "statusCode": "adBuyStatusNotAllowed",
    "statusName": "Статус закупки должен быть один из: Опубликовано"
}
```

___

P.S: В случае если ресурс недоступен ( самрук/госзакуп ) ответ будет следующим ( требует дополнительных тестов уже во время того когда самрук и госзакуп будут недоступны ) 
```json5
{
    "data": {},
    "statusCode": "sourceNotAvailable",
    "statusName": "Внешний источник недоступен"
}
```
HTTP код - 200
